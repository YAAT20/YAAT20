## 👨‍💻 Sobre mí

Soy **Bachiller en Ingeniería de Sistemas por la Universidad Nacional de Cajamarca**, con orientación hacia el desarrollo **Full-Stack y DevOps**.

Tengo experiencia práctica en el ciclo completo de soluciones tecnológicas: **análisis, desarrollo, bases de datos, despliegue, administración de servidores, integración de servicios y mantenimiento en producción**.

Mi principal stack de desarrollo es **Python + Django**, acompañado de JavaScript y tecnologías de infraestructura como **Linux, Docker, Nginx, Gunicorn y Cloudflare**.

He desarrollado sistemas para entornos académicos y gastronómicos, automatizando procesos administrativos y operativos que anteriormente requerían una importante cantidad de trabajo manual.

## 🚀 Experiencia y proyectos destacados

### 🎓 Ecosistema Académico | Academia Robert Hooke

Sistema web integral para centralizar la gestión académica y administrativa de la institución.

Desarrollé funcionalidades para la gestión de **matrículas, alumnos, apoderados, horarios, ciclos, cobranza, pagos, cuotas, deudas y reportes financieros**, además de generación de documentos y exportación de información.

**Principales implementaciones**

* Automatización de aproximadamente **70 % de los procesos administrativos**.
* Gestión de pagos, cuotas, deudas y seguimiento de cobranza.
* Generación de fichas y constancias en PDF.
* Exportación de información a Excel.
* Integración con **WhatsApp** y **Firebase Cloud Messaging (FCM)**.
* Sistema de autenticación, roles y control de acceso.
* Interfaces desarrolladas con **Tailwind CSS y Select2**.
* Módulo de marketing institucional para publicaciones, eventos, galerías y recursos.

**Stack**

`Python` · `Django` · `MariaDB` · `JavaScript` · `Tailwind CSS`

### 📚 Banco de Preguntas & Generación de Exámenes

Plataforma web desarrollada para gestionar bancos de preguntas y automatizar la creación de evaluaciones.

**Principales implementaciones**

* Organización jerárquica de **universidades, cursos, temas y preguntas**.
* Búsqueda y filtrado de contenido.
* Carga masiva de preguntas.
* Gestión de documentos DOCX.
* Generación automática de exámenes y solucionarios.
* Composición de documentos mediante `python-docx` y `docxcompose`.
* Exportación de información en CSV.
* Prácticas digitales con preguntas aleatorias y control de tiempo.
* Evaluación automática de resultados.
* Integración con **OnlyOffice** para edición y visualización desde el navegador.
* Autenticación mediante **JWT** para integración con OnlyOffice.
* Roles y permisos para administradores, supervisores y estudiantes.
* Dashboard para estadísticas y seguimiento.

**Resultado**

> Automatización aproximada del **80 % del proceso de creación de exámenes**.

**Stack**

`Python` · `Django` · `MariaDB` · `JavaScript` · `OnlyOffice`

### 🍽️ Sistema POS & Gestión Operativa | Restaurante MyM

Sistema POS desarrollado para centralizar la operación de un restaurante en una única plataforma.

**Módulos desarrollados**

* Gestión de mesas.
* Pedidos y estados de atención.
* Consumo en local y pedidos para llevar.
* Gestión de cocina y preparación.
* Gestión de menú.
* Inventario y stock.
* Recetas e ingredientes.
* Entradas y salidas de inventario.
* Alertas de bajo stock.
* Caja y cierre de caja.
* Pagos en efectivo, Yape, Plin, tarjetas y transferencias.
* Pagos parciales y pagos divididos.
* Dashboards y reportes.
* Generación de boletas en PDF.
* Envío de documentos mediante WhatsApp.
* Integración con impresoras térmicas para comandas.

**Infraestructura**

`VPS Linux` · `Nginx` · `Gunicorn` · `Cloudflare`

**Resultado**

> Centralización de pedidos, cocina, caja, inventario, menú y reportes en una única plataforma, reduciendo tareas manuales y mejorando el control operativo.
